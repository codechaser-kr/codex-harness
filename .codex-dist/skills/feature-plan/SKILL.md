# Feature Plan

이 스킬은 `기능변경` 이슈의 실제 구현 전에 변경 계획 초안을 만든다. 변경 계획 사용자 결정, 이슈 반영, 구현 흐름 진입은 Workflow Engine의 후속 작업에서 처리한다.

## 먼저 읽을 문서

- `../github-workflow-engine/references/workflow-engine-rules.md`
- `../github-workflow-engine/references/github-templates.md`

## 입력

- 기능변경 이슈 번호와 본문
- 완료 기준 체크리스트
- 연관 정책검토, 기능제안, 기능결함 이슈
- 관련 설계 문서
- 이미 merge된 연결 PR
- 현재 코드 상태

## 책임

1. 기능변경 이슈의 작업 범위와 완료 기준을 읽는다.
2. 정책검토 결과와 관련 설계 문서를 함께 참조한다.
3. 구현 단위를 하나 이상의 브랜치와 PR 단위로 나눈다.
4. 구현 순서와 각 구현 단위의 검증 기준을 제안한다.
5. 기존 merge PR이 이미 충족한 완료 기준을 분리한다.
6. Workflow Engine이 검토할 변경 계획 초안을 반환한다.

## 계획 초안 형식

- 기준 이슈
- 참조한 설계 문서와 연관 이슈
- 현재 코드 상태 요약
- 이미 반영된 PR 또는 완료 기준
- 제안 브랜치 수
- 구현 단위별 범위
- 구현 순서
- 구현 단위별 검증 기준
- 구현 흐름으로 넘길 첫 구현 단위
- Workflow Engine이 확인할 보류 질문

Workflow Engine은 이 계획 초안을 사용자 결정 대상으로 제시하고, 확정된 계획만 기능변경 이슈의 `작업 범위는 어디까지인가요?`, `완료 기준은 무엇인가요?`, 필요하면 `추가 정보`에 반영한다.
