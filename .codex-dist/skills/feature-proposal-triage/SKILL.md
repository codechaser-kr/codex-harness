# Feature Proposal Triage

이 스킬은 `기능제안` 이슈의 진행 방향 후보, 판단 근거, 방향별 완료 기준 후보를 만든다. 진행 방향 확정, 기능제안 이슈의 `판단 결과` 반영, 완료 기준 추가, 정책검토 또는 기능변경 전환, 기능제안 이슈 종료는 Workflow Engine의 후속 작업에서 처리한다.

## 먼저 읽을 문서

- `../github-workflow-engine/references/workflow-engine-rules.md`에서 `Feature Proposal Triage 출력 판정 규칙` 섹션만 읽는다.
- `../github-workflow-engine/references/github-templates.md`

## 입력

- 기능제안 이슈 번호와 본문
- `무엇을 제안하나요?`, `왜 필요한가요?`, `현재 상태는 어떤가요?`
- 연관 이슈
- 관련 설계 문서, 정책 문서, 코드, 템플릿, 스킬, 설정 상태
- 이미 merge된 연결 PR

## 책임

1. 기능제안 이슈의 제안 내용, 필요성, 현재 상태를 확인한다.
2. 관련 이슈, 설계 문서, 코드, 템플릿, 스킬, 설정에서 판단 근거를 수집한다.
3. `진행하지 않음`, `정책 검토 필요`, `기능 변경 필요` 후보를 각각 검토한다.
4. 각 후보의 근거와 위험을 제시한다.
5. 가장 적합한 추천 방향이 있으면 근거와 함께 제시하되, 최종 판단은 사용자 결정으로 남긴다.
6. Workflow Engine이 확인할 보류 질문을 반환한다.

진행 방향을 확정할 수 있는 근거가 부족하면 후보를 강제로 추천하지 말고 `보류 질문`에 확인할 내용을 기록한다.

## 출력

- 기존 `필수 출력 섹션`의 진행 방향 후보, 추천 방향, `보류 질문`만 반환한다.
- 추천 방향은 사용자 검토용 후보이며 기능제안 이슈의 상태 변경이나 후속 이슈 전환 요청이 아니다.

## 하지 않는 일

- 진행 방향, 기능제안 이슈의 `판단 결과`, 완료 기준, 이슈 종료를 확정하거나 GitHub에 반영하지 않는다.
- 정책검토 또는 기능변경 이슈를 생성·갱신하지 않고, 입력으로 확인된 범위를 넘는 구현 또는 정책 결정을 추가하지 않는다.

## 사용자 결정

- 추천 방향을 사용자 결정으로 해석하지 않는다. 사용자에게 제시할 선택지와 결정 결과의 반영은 `github-workflow-engine`의 책임이다.

## 중단 조건

- 제안 내용, 현재 상태, 관련 근거가 없거나 서로 충돌해 후보 비교가 불가능하면 추천 방향을 확정하지 않는다.
- 현재 기능제안 이슈 또는 연결된 근거의 범위를 벗어난 요청이면 구체적인 누락·충돌·범위 밖 사유와 재개에 필요한 입력을 `보류 질문`에 반환한다.

## 후속 전이

- 제어와 기존 출력 구조를 `github-workflow-engine`에 반환한다.
- Workflow Engine이 산출물 판정과 사용자 결정을 처리해 `진행하지 않음`, 정책검토, 기능변경 중 다음 전이를 확정한다.

## 판정 기준

- `진행하지 않음`: 제안이 이미 충족됐거나, 현재 목표와 맞지 않거나, 후속 이슈로 만들 만큼의 사용자 가치 또는 실행 범위가 확인되지 않는다.
- `정책 검토 필요`: 구현 전에 정책, 설계 기준, 운영 규칙, 문서 간 기준 중 하나를 먼저 결정해야 한다.
- `기능 변경 필요`: 구현 목표와 완료 기준을 기능변경 이슈로 바로 정리할 수 있고, 선행 정책 결정이 필요하지 않다.

두 방향 이상이 가능하면 자동으로 하나를 확정하지 말고 각 방향의 근거와 위험을 비교해 제시한다.

## 필수 출력 섹션

기능제안 진행 방향 판단 결과는 다음 섹션과 항목을 순서대로 빠짐없이 채운다. 필수 내용을 채울 수 없으면 진행 방향을 확정하지 말고 `보류 질문`에 확인할 내용을 기록한다.

- `기준 이슈`
- `판단 맥락`: 현재 상태와 참조한 설계 문서, 코드 위치, 연관 이슈
- `진행 방향 후보`
  - `진행 방향`: `진행하지 않음`, `정책 검토 필요`, `기능 변경 필요` 중 하나
  - `판단 근거와 위험`
- `추천 방향`
- `보류 질문`: Workflow Engine이 확인할 내용
