# Fix Plan

이 스킬은 `기능결함` 이슈의 실제 수정 전에 기능 결함 해결 계획 초안을 만든다. 계획 승인, 이슈 반영, 기능 구현 흐름 진입은 Workflow Engine의 Human Checkpoint와 후속 액션에서 처리한다.

## 먼저 읽을 문서

- `../github-workflow-engine/references/workflow-engine-rules.md`
- `../github-workflow-engine/references/github-templates.md`

## 입력

- 기능결함 이슈 번호와 본문
- 문제 현상
- 재현 과정 또는 확인 위치
- 원인과 해결 방향
- 완료 기준
- 관련 정책검토 결과
- 이미 merge된 연결 PR
- 현재 코드 상태

## 책임

1. 기능결함 이슈에 기록된 원인과 해결 방향을 확인한다.
2. 정책검토 결과가 있으면 기능결함 이슈에 반영됐는지 확인한다.
3. 결함 해결 단위를 하나 이상의 브랜치와 PR 단위로 나눈다.
4. 해결 순서와 각 해결 단위의 검증 기준을 제안한다.
5. 기존 merge PR이 이미 충족한 완료 기준을 분리한다.
6. 이슈 본문을 직접 갱신하지 않고 Workflow Engine이 검토할 계획 초안을 반환한다.

## 계획 초안 형식

- 기준 이슈
- 문제와 확인 위치
- 기록된 원인
- 제안 또는 기록된 해결 방향
- 현재 코드 상태 요약
- 이미 반영된 PR 또는 완료 기준
- 제안 브랜치 수
- 결함 해결 단위별 범위
- 해결 순서
- 해결 단위별 검증 기준
- 기능 구현 흐름으로 넘길 첫 해결 단위
- Workflow Engine이 확인할 보류 질문

Workflow Engine은 이 계획 초안을 사용자 승인 대상으로 제시하고, 승인된 계획만 기능결함 이슈의 `원인과 해결 방향은 무엇인가요?`, `완료 기준은 무엇인가요?`, 필요하면 `추가 정보`에 반영한다.
