# Policy Review Next Triage

정책검토 결과의 구현 범위와 열린 기능변경 이슈를 비교해 기능변경 전환 방향 후보를 만든다. 방향 확정과 이슈 갱신 또는 생성은 Workflow Engine이 처리한다.

## 먼저 읽을 문서

- `../github-workflow-engine/references/artifact-output-contract.md`에서 `Policy Review Next Triage 출력 판정 규칙` 섹션만 읽는다.
- `../github-workflow-engine/references/github-templates.md`

## 입력

- 정책검토 이슈 번호와 본문
- 정책검토 이슈의 `검토 결과`와 `설계 반영 후 기능변경 전환 범위`
- 반영된 설계 문서와 직접 연결된 merged PR
- 연관 이슈
- 열린 기능변경 이슈의 번호, 제목, 본문, 라벨, 연결 PR과 완료 기준 상태

## 책임

1. 정책검토 결과에서 기능변경으로 구현할 목표와 범위를 추출한다.
2. 기능변경 라벨이 있는 열린 이슈를 제목, 본문, 연관 이슈, 작업 범위 기준으로 탐색하고 확인 대상과 제외 근거를 기록한다.
3. 관련 후보마다 목표와 범위의 일치점, 추가해야 할 범위, 충돌, 진행 상태 영향을 비교한다.
4. 기존 기능변경 이슈 반영 후보와 새 기능변경 이슈 생성 후보를 제시한다.
5. 가장 적합한 추천 후보가 있으면 근거와 함께 제시하되 최종 판단은 사용자 결정으로 남긴다.
6. 필수 입력이 없거나 후보 비교 결과가 불명확하면 `보류 질문`에 확인할 내용을 기록한다.

## 판단 기준

- 기존 기능변경 이슈 반영: 구현 목표가 같고, 정책검토 결과를 추가해도 기존 이슈의 목적과 완료 이력을 흐리지 않으며, 남은 작업 범위와 완료 기준을 명확히 갱신할 수 있다.
- 새 기능변경 이슈 생성: 관련 열린 이슈가 없거나, 기존 후보와 목표가 다르거나, 범위 추가가 기존 이슈의 목적·진행 상태·완료 이력을 불명확하게 만든다.
- 후보가 여러 개면 관련성만으로 하나를 확정하지 말고 후보별 차이와 위험을 모두 제시한다.
- 완료됐거나 종료된 기능변경 이슈는 기존 이슈 반영 후보로 제시하지 않는다.

## 출력

- 기존 `필수 출력 섹션`의 전환 후보, 추천 후보, `보류 질문`만 반환한다.
- 기존 이슈 반영 또는 새 이슈 생성은 후보 비교 결과이며 이슈 갱신·생성 요청의 확정값이 아니다.

## 하지 않는 일

- 정책검토 결과의 기능변경 전환 방향, 대상 이슈, 현재 Workflow 상태를 확정하지 않는다.
- 기능변경 이슈를 생성·갱신하거나 정책검토 이슈, 설계 문서, GitHub 상태를 변경하지 않는다.
- 열린 기능변경 이슈와 정책검토 결과에서 확인된 범위를 넘는 구현 범위를 추가하지 않는다.

## 사용자 결정

- 추천 후보를 사용자 결정으로 해석하지 않는다. 기존 이슈 반영 또는 새 이슈 생성의 선택과 실행 요청 확정은 `github-workflow-engine`이 처리한다.

## 중단 조건

- `검토 결과`, 설계 반영 후 전환 범위, 열린 기능변경 이슈 상태가 없거나 충돌하면 추천 후보를 확정하지 않는다.
- 후보 비교에 필요한 입력이 누락되었거나 요청 범위 밖 이슈 변경이 필요하면 사유와 재개에 필요한 입력을 `보류 질문`에 반환한다.

## 후속 전이

- 제어와 기존 출력 구조를 `github-workflow-engine`에 반환한다.
- Workflow Engine이 산출물 판정과 사용자 결정을 거쳐 기존 이슈 반영 또는 새 기능변경 이슈 생성의 다음 작업을 확정한다.

## 필수 출력 섹션

다음 섹션과 항목을 순서대로 빠짐없이 채운다. 필수 내용을 채울 수 없으면 후보를 강제로 추천하지 말고 `보류 질문`에 확인할 내용을 기록한다.

- `기준 정책검토 이슈`
- `기능변경 전환 범위`: 정책검토 결과에서 추출한 기능변경 목표와 범위
- `탐색 결과`: 확인한 열린 기능변경 이슈와 제외 근거
- `전환 후보`
  - `후보 ID`
  - `진행 방향`: `기존 기능변경 이슈 반영` 또는 `새 기능변경 이슈 생성`
  - `대상 이슈`: 기존 이슈 반영 후보의 이슈 번호. 새 이슈 생성 후보이면 비워 둔다.
  - `반영 범위`
  - `판단 근거와 위험`
- `추천 후보`: `전환 후보`의 `후보 ID` 또는 빈 값
- `보류 질문`

적합한 기존 후보가 없으면 제외 근거와 새 기능변경 이슈 생성 후보를 제시한다.
