# Repository Evolution Workshop

이 디렉터리는 `codex-harness` 저장소를 기반으로 학습과 개선을 병행하기 위한 워크숍 문서를 관리한다.

이 문서들은 현재 설계를 확정하는 공식 설계 문서가 아니다. 개념 학습, 저장소 조사, 가설 검토, 개선 후보 도출을 위한 작업 문서다. 검증과 정책 결정을 거쳐 확정된 내용만 기존 설계 문서, 스킬, 코드, 테스트에 반영한다.

## 문서 구성

- `roadmap.md`: Phase 1~10 전체 학습·개선 로드맵
- `execution-guide.md`: 모든 Phase에 공통으로 적용하는 진행 방식
- `phases/`: 각 Phase의 Day 단위 상세 학습 계획

## 진행 순서

1. `roadmap.md`에서 전체 방향과 현재 Phase를 확인한다.
2. `execution-guide.md`의 공통 원칙을 확인한다.
3. `phases/` 아래의 현재 Phase 문서를 Codex CLI에서 실행한다.
4. 최신 저장소를 직접 조사하고 학습 결과와 개선 후보를 기록한다.
5. 명백한 오류가 아닌 변경은 정책 검토 또는 기능 제안 절차를 거친다.
6. 확정된 결론만 공식 설계 문서와 구현에 반영한다.

## 기본 원칙

- 과거 대화보다 최신 저장소의 코드와 문서를 우선한다.
- 학습 결과와 공식 설계를 구분한다.
- 현재 구조의 의도와 장점을 먼저 이해한다.
- 개선을 전제로 조사하지 않는다.
- 변경은 작고 검증 가능한 단위로 진행한다.
- 중단 후 새 세션에서도 문서만으로 재개할 수 있어야 한다.
